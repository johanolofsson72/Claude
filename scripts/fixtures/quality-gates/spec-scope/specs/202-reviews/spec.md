# Spec

Customers review products they bought.

## Scope

In scope: writing a 1-5 star review with text for a delivered order line.

Out of scope: moderation tooling, photos.

## Acceptance criteria

- A customer with a delivered order line can post one review per product.
- The review shows on the product page immediately.
- Staff can hide a review from a moderation queue with a reason code.

## Notes

The register row carries the one-line goal; this file is the source of truth for the behaviour.
Any change to the criteria goes through clarify before plan.
