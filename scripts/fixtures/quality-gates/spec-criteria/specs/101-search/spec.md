# Spec

Customers search the catalog by name.

## Scope

In: free-text search over product names. Out: facets.

## Acceptance criteria

- Search results appear fast.
- Results are ordered by relevance.
- An empty query shows the 20 newest products.

## Notes

The register row carries the one-line goal; this file is the source of truth for the behaviour.
Any change to the criteria goes through clarify before plan.
